THE FIX IN THREE STEPS

Check first, then copy

Here is our fix. It is just three lines, but it is a habit that protects us every time. First we measure: we check how much space we actually have, then we copy only what fits, at most 7 characters so we leave room for the null terminator.

n = min(size, 7)
memcpy(buffer, input, n);   buffer[n] = null
n = 7 ABCDEFG + null blocked 8

PROOF · SAME INPUT, TWO OUTCOMES

Same input, opposite outcome

This compares the same 15-letter input in the two cards below. Without the check, it tried a write of 16 at offset 40, so the sanitizer reported stack-buffer-overflow and exited with 1. With the check, it kept 7 plus null, blocked 8, printed ABCDEFG, and exited with 0 because the bound removed the bad access.
