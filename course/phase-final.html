TOOLBOX · SAFE APIS

Tools that carry their size

This section lists safe tools that always know their size. Each card names one tool, such as std::string, string_view, snprintf, or memcpy with min, and states its single rule. All of them enforce the same boundary: never copy more than the destination holds.

std::string
Grows itself, size always known.
string_view / span
Borrow with bounds, never own blindly.
snprintf
Prints at most n, always terminates.
memcpy + min
Copy min(size, capacity minus 1), seal null.
static analysis + sanitizers
Catch in review, prove in tests. Our course habit, every copy.
WHY IT MATTERS

The same shape broke real software

This section explains why the pattern matters outside this course. The same unchecked copy has appeared in widely used software, where extra bytes overwrote nearby memory and caused crashes and costly fixes. The summary here keeps the focus on defense: check the size first, then copy.
