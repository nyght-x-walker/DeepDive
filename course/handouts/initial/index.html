HANDOUT · INITIAL PROTOTYPE · PRINTABLE COMPANION

Where memory lives.

This handout is the quiet companion to our first chapter. We learn where memory lives: the stack clears itself when the function ends, the heap stays until we return it, and the smart pointer holds heap space and returns it for us. It follows initial_prototype.cpp box for box. One page you can print or keep beside the playground.

CODE · THREE OWNERS

One record, three homes

struct MyData {
  int id;
  char name[10];
};

int main() {
  MyData stackData; stackData.id = 42;  // stack, auto
  MyData *heapData = new MyData(); heapData->id = 100;  // heap, manual
  delete heapData;
  auto smartData = make_unique<MyData>(); smartData->id = 200;  // heap, auto (RAII)
}
Download .cpp

sizeof(MyData) is 14 bytes · addresses shown in the playground are illustrative

WHAT TO TAKE AWAY

Four lines to remember

  • Stack is fast and automatic, freed when the function ends.
  • Heap with new must be freed with delete, or it leaks.
  • unique_ptr is heap but freed automatically, safest of the three.
  • All later chapters use the same street of boxes, just with different owners.
