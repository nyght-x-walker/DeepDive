Small signs, big difference.

In the last chapter we learnt why floats approximate and ints count exactly. In this chapter we look at small signs that change meaning. Plus plus before or after, minus minus, and compound forms like plus equal. Then we see how the same signs can be defined for our own types with operator overloading.

PRE AND POST

When does the plus happen

Plus plus after gives the old value, then adds one. Plus plus before adds one, then gives the new value. The same holds for minus minus. Press Step below to watch i and x change line by line. In real code we prefer the plain form unless we need the value right away, because it is easier to read.

int i = 5;
int x = i++; // x is 5, i becomes 6
int y = ++i; // i becomes 7, y is 7
COMPOUND ASSIGNMENT

Update in one place

Compound forms are short for longer math. Plus equal adds and stores. Minus equal, multiply equal, and divide equal do the same. They keep the update in one place, so there is less to misread. Use them when you update the same variable you read.

i += 2; // i = i + 2
i *= 3; // i = i * 3
OPERATOR OVERLOADING

Same signs for our own types

Operator overloading lets our own types use the same signs. We define what plus plus means for a Counter, what plus means for a small string, what equal means for a record. The rule stays the same as for built-in types. Keep the meaning expected. Plus plus should step forward by one, not jump or print.

Counter& operator++() // pre: step, return new
Counter operator++(int) // post: copy old, step, return old
