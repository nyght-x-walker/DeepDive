CHAPTER 1 · INITIAL

Where memory lives.

Before we talk about overflow, we need to know where C++ keeps our variables. In this chapter we meet three places. The stack clears itself when the function ends. The heap stays ours until we return it. And the smart pointer returns itself for us. In the lab you allocate boxes and watch what leaks and what frees itself.

THE STACK

Local space that clears itself

The stack holds local variables, like a tray on a desk. You place your box, you work, and when the function ends the tray clears itself. There is nothing to return. It is fast and automatic, but small, and trays sit side by side. That closeness matters later when we talk about writing past the end.

void serve() {
  char tray[8]; // stack carton, auto-freed at the closing brace
}
THE HEAP

Space you must return

The heap is like a storage room. You request space with new, and it stays yours until you return it with delete. If you forget, it stays held but useless. That is what we call a leak. In the lab you will see leaked bytes stay counted until you free them.

char* room = new char[8]; // ours until…
delete[] room; // …we return it. Skip this line and it leaks.
THE SMART POINTER

Heap space with automatic return

A smart pointer gives you heap space with automatic return. Think of a box tied to your wrist with a string. When you leave, it comes back with you, so there is no leak. It removes forgetting, but it does not remove the need to stay inside the buffer. You still must not write past the end.

auto room = std::make_unique<char[]>(8); // freed by itself, no delete needed
