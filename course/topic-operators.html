How C++ groups expressions.

In the DeepDive we checked every copy against the size of the buffer. Now we look at the wider C++ language from Topic 3. In this chapter we learn how C++ groups expressions. Precedence decides which operator runs first. Associativity decides the order when precedence is equal. Our style rule is simple. When unsure, add parentheses to show what you mean.

STYLE AND CONVENTIONS

Show what you mean

Coding style is how we make grouping visible. We use clear names, braces on every if, and parentheses around mixed operators. The compiler follows precedence even without parentheses. Readers should not have to memorise the table. If an expression mixes plus and multiply, or and and or, we write the parentheses we mean.

int x = (a + b) * c; // parentheses show grouping
if ((x > 0) && (y < 8)) { } // braces + parens, no guessing

ASSOCIATIVITY

Same level, which side first

Associativity decides the order when precedence is equal. Most operators group left to right, so a minus b minus c means a minus b first, then minus c. Assignment groups right to left, so a equals b equals zero sets both to zero from the right. When a line mixes both, we split it or add parentheses rather than rely on memory.

a - b - c // (a - b) - c, left to right
a = b = 0; // a = (b = 0), right to left
